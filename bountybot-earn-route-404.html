BountyBot earn route returns a bounty-specific 404

Prepared for the public BountyBot bug bounty review.

Summary

The direct URL https://bountybot.com/earn currently renders a 404 Page Not Found state with the technical detail Bounty not found. The active public earning feed is available at https://bountybot.com/feed.

If /earn is a legacy, bookmarked, or intuitive earning URL, users should be redirected to /feed instead of landing on a bounty-specific error page.

Reproduction steps

  1. Open https://bountybot.com/earn.
  2. Observe the visible 404 Page Not Found state.
  3. Note the technical detail shown on the page: Bounty not found.
  4. Open https://bountybot.com/feed.
  5. Observe that the public bounty feed loads normally.

Expected result

/earn should redirect to /feed, or the route should show a route-aware page that directs earn-seeking users to the public feed.

Impact

This is a low-to-medium conversion and user-experience issue. Users who type or follow the intuitive /earn URL can hit a dead page even though the earning feed exists.

Suggested fix

Add a permanent or temporary redirect from /earn to /feed. If the route is intentionally unsupported, replace the generic bounty lookup failure with a helpful destination link.

Verification notes

Observed:
https://bountybot.com/earn -> visible 404 Page Not Found / Bounty not found
https://bountybot.com/feed -> public bounty feed loads
